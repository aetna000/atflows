# AtFlows 0.1.0

Install with `python -m pip install --upgrade atflows`. Bun 1.1 or newer is required to run the local server.

This is the first stable AtFlows package release for local use. It includes the model proxy, a dashboard on `http://localhost:1337`, and OTLP/HTTP JSON and protobuf ingestion for traces, logs, and metrics.

## Changes since 0.1b6

- Added local dashboard accounts with Viewer, Investigator, Evidence Collector, and Administrator roles. Administrators can create accounts, change roles, disable access, and reset passwords. Session changes take effect on live dashboard connections.
- Kept `atflows init`'s prefilled Administrator sign-in while replacing the password-bearing URL with a one-use, short-lived local setup token.
- Expanded the Connect catalog and its on-screen setup guidance for Codex, OpenClaw, Claude Code, LangChain, Pydantic AI, and AtBots. The catalog distinguishes working connections from planned ones.
- Improved activity tables, trace details, local and UTC timestamps, JSON highlighting, exports, and model-data clearing.
- Added a database location view in Settings and clearer local authentication recovery guidance.
- Hardened browser-origin checks on telemetry ingestion while retaining Originless local SDK ingestion.

## Current limits

The proxy and OTLP receiver remain unauthenticated on their configured local listeners. Bind them only to a trusted interface. This release uses a local SQLite database; external production databases, hosted tenants, AtFlows MCP, and AtMem or AtBot package integration remain planned. OpenClaw's tested OTLP diagnostics correlate by trace ID; its tested spans did not include a conversation session ID.

Upgrading from a beta retains the default `~/.atflows` data directory. The server needs Bun and network access on its first launch to prepare its bundled runtime.
