# AtFlows 0.1b2

AtFlows now uses the same plural name for the GitHub repository, dashboard, Python package and CLI. The dashboard header links to the PyPI package and shows the correct `pip install atflows` command. Repository and documentation links point to `aetna000/atflows`.

## Install or upgrade

```bash
python -m pip install --upgrade atflows==0.1b2
atflows
```

The first launch still needs Bun 1.1 or newer and network access to prepare the server workspace in `~/.cache/atflows`. The dashboard defaults to port 3000, the proxy to port 8080 and data to `~/.atflows`. No database migration is needed from 0.1b1.

The upstream LLMFlow copyright and MIT license remain in `LICENSE`; Javad Taghia is credited for the AtFlows changes. Provider keys remain necessary for forwarding to external model APIs. The full upstream server suite's local Ollama model case requires `llama3.2:1b` to be installed.
