# AtFlows 0.1b1

Initial beta rebrand of LLMFlow as AtFlows, with dashboard colors and styling based on the AtMem design language. Adds the `atflows` Python package and CLI, bundling the server and dashboard. The upstream MIT license and author credit remain in the repository and package.

## Install

```bash
python -m pip install atflows==0.1b1
atflows
```

Upgrade this beta with `python -m pip install --upgrade atflows` once a newer release is available. Bun 1.1 or newer must be installed to run the server. The first `atflows` launch prepares Bun workspace dependencies in `~/.cache/atflows` and requires network access. The local dashboard defaults to port 3000 and the proxy to 8080.

## Migration and compatibility

This is a new package; no migration from an earlier AtFlows release is required. The default data directory is `~/.atflows`. Existing LLMFlow installations and databases are not modified or imported automatically. The observability proxy and OTLP endpoints follow the upstream implementation.

## Limitations

Provider forwarding requires the relevant provider API keys. Bun is an external runtime dependency. The Python wheel installs without Bun, but the `atflows` command requires it. The upstream full server test suite includes a local Ollama model test that fails when `llama3.2:1b` is unavailable.
