AtFlows changes are now licensed under Apache License 2.0. The original LLMFlow code remains subject to its MIT license and Helge Sverre's copyright notice, distributed as `LICENSE-MIT-LLMFLOW`. The `NOTICE` file explains this provenance. Python and npm package metadata declare both obligations.

## Install or upgrade

```bash
python -m pip install --upgrade atflows==0.1b3
atflows
```

Bun 1.1 or newer is still required to run AtFlows. First launch prepares dependencies in `~/.cache/atflows` and needs network access. The dashboard defaults to port 3000, the proxy to 8080, and data to `~/.atflows`. No database migration is needed from 0.1b2. Provider API keys are still needed for forwarding.
