# AtFlows 0.1.6

Dashboard appearance release, coordinated with AtMem 2.3.13 and the refreshed
AtMem.ai website. Collection, storage, accounts and login behavior are unchanged.

- The dashboard and sign-in page use the AtMem.ai Architecture Canvas theme:
  self-hosted DM Sans and Manrope fonts (SIL OFL), softer surfaces and the
  AtMem.ai mark with a consistent "AtMem.ai | AtFlows" name and page title.
- The dashboard now opens in the light theme. Dark mode is used only when you
  choose it with the theme toggle; the choice is remembered in the browser.
  Previously a first visit followed the operating system colour scheme.

## Install or upgrade

```sh
python -m pip install --upgrade atflows==0.1.6
atflows --version
```

Python 3.10+ and Bun 1.1+ are required for the service. Stop the instance you
own, upgrade and restart with `atflows start`. Existing traces, accounts,
configuration and dashboard login are retained; no migration is needed.

AtMem-managed installations use the exact AtFlows pin selected by AtMem;
upgrade AtMem instead of overriding that dependency. AtMem 2.3.13 selects 0.1.6.
Standalone AtFlows retains its own accounts; delegated mode uses AtMem accounts.

## Compatibility and limits

Visual change only. Visitors who had not chosen a theme and whose OS prefers
dark will now see light until they use the toggle. Native Hermes integration is
still unavailable on Windows; use a supported host or WSL. AtFlows reports
telemetry and known prices; it does not authorize memory or prove a workflow
succeeded. Website publication is a separate reviewed step.
