# AtFlows 0.1b5 experimental release

```bash
python -m pip install --upgrade atflows==0.1b5
atflow status
```

`atflow` and `atflow status` list every live AtFlows dashboard and proxy discovered on this computer, including ports reassigned when defaults were occupied. `atflows status` is equivalent. `atflows` still starts a server; `atflow start` starts one explicitly. Stale process records are ignored after health checks.

All 17 integration guide URLs now open the guide inside the Connect dashboard. The dashboard loads guide content through its authenticated API and renders local guide links as web navigation. Links to repository specifications and examples open their GitHub pages.

For first setup, run `atflows init`. Lost Administrator access can be recovered with `atflows users recover-administrator`.
