# AtFlows 0.1b6 experimental release

Install with `python -m pip install --upgrade atflows==0.1b6`.

AtFlows now accepts OTLP/HTTP protobuf and JSON at `/v1/traces`, `/v1/logs`, and `/v1/metrics`. Protobuf requests support gzip, bounded bodies, signal-specific protobuf responses, and partial-success counts.

OpenClaw `2026.9.1` with the matching official `@openclaw/diagnostics-otel@2026.9.1` plugin was tested against both the source server and a clean wheel built from this tree. Traces, logs, metrics, model identity, and token usage arrived. The tested OpenClaw spans did not carry a session ID attribute, so they correlate by trace ID but do not populate the Sessions view as a conversation group.

The connection catalog and [OpenClaw setup guide](../integrations/openclaw.md) now show the direct path. The receiver remains local and unauthenticated; hosted ingestion still depends on the production authentication and tenant-storage work.
