proxy/OTLP filtering a stable-release prerequisite. S002–S005 remain open.
The shared filter covers Hermes labels only; general telemetry, diagnostics and
export need implementation and canary/forwarding/upgrade qualification.

Complete the existing security feature, review it, rerun its installed gates,
then publish AtFlows before merging AtMem's new dependency pin. No global

## Security correction and rerun

The initial blocker above has now been implemented on
`fix/stable-telemetry-redaction`:

- Shared bounded JSON-copy filtering before inserts/hooks, telemetry fanout,
  telemetry API reads, diagnostic logging, export queues and outbound payloads.
- Six security boundary tests, 65 assertions, pass both from source and the
  freshly installed wheel's bundled runtime (not source imports).
- Canaries cover structured/embedded JSON and OTLP attributes, secret text,
  URLs, SQLite/WAL, diagnostics, live JSON/protobuf ingestion, authenticated

  authorization remains unchanged.
- Loopback proxy requests retain their input content; streamed/non-streamed
  response bytes are unchanged. An injected legacy unfiltered database row is
  filtered on API read, without claiming disk erasure.
- Existing `PROVIDERS=none` server regression, continuity fixtures, typechecks,
  dashboard build, browser navigation/Hermes tests, wheel/sdist metadata and
  isolated installed CLI/dependency checks pass.

Historical initial failures are retained above. Publication still requires the
