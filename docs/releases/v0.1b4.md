# AtFlows 0.1b4 experimental release

## Install

```bash
python -m pip install --upgrade atflows==0.1b4
atflows init
```

Bun 1.1 or newer is required. The first launch prepares the bundled runtime in `~/.cache/atflows/0.1b4`.

## Changes

- Added the Connect workspace with guided setup, running-server endpoints, inline integration instructions, and safe local Codex preview/apply/undo.
- Added local Administrator sign-in and an AtMem-style top navigation. `atflows init` creates a temporary password and opens the sign-in page; users choose a permanent password. `atflows users recover-administrator` resets lost access.
- Added Codex connection nicknames, preserved when telemetry is cleared; model names remain separate.

The dashboard defaults to port 1337 and proxy to 8080. The actual addresses are printed at startup. Direct OpenClaw OTLP protobuf, automatic setup for other tools, and AtFlows AtBot help remain planned.
