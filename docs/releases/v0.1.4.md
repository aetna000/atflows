# AtFlows 0.1.4

Published stable on 2026-10-20; exact registry installation verified before
merging AtMem's new dependency pin. See [validation](v0.1.4-validation.md).

Stable companion release for AtMem 2.3.9. AtFlows provides local request traces,
token and cost inspection, Hermes observation, and continuity visibility.

## Install or upgrade

```sh
python -m pip install --upgrade atflows==0.1.4
atflows --version
atflows
```

Standalone use requires Bun. With AtMem 2.3.9, AtFlows is installed automatically
and AtMem manages its local runtime; use `atmem up` and the dashboard links in
`atmem status`. Do not run a second standalone server on the same ports.

Python 3.10–3.13 remain supported. Existing trace databases and configuration are
preserved; this release changes no database schema. Provider routing and capture
are configured explicitly. Code memory belongs to AtMem, not the trace database.
An observed trace is not proof that an external action completed.

Telemetry filtering is now default-on across generic proxy/OTLP storage,
dashboard, diagnostics and export boundaries. Provider traffic is unchanged.
See [supported patterns, limits and historical-data handling](../telemetry-redaction.md).

For setup see [README](../../README.md) and
[continuity integration](../integrations/continuity.md).
