# AtFlows 0.1.8

Completes the pink branding from 0.1.7 by updating the browser-tab icon too. The dashboard matches AtMem.ai’s pink branding. The existing AtMem logo keeps its artwork, with a #F3A2B4 dot in both light and dark mode. Pink navigation, focus and hover accents use darker rose for readable text. Success, warning and error indicators keep their meanings.

## Install or upgrade

```sh
python -m pip install --upgrade atflows==0.1.8
atflows --version
```

Let active work finish, stop services you own, upgrade and reopen the dashboard. Preserve the existing data directory; no schema migration or configuration change is required. This release changes appearance only, not authentication, collection, supervision or provider behavior. Existing platform and runtime requirements still apply.

AtFlows can run standalone or through AtMem 2.3.14, which pins this release. Bun remains required.
