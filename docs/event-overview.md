# Grouped event overview

Activity → Timeline includes an event-count chart above the event list.
Group by tool, service, model, event type, or hour. Click a bar to inspect
its events; click it again or choose **Show all loaded events** to clear it.
Changing the grouping clears the selection. Existing search/time/type filters
apply before grouping. Hours display in local time.

This view describes only the latest 100 matching events loaded by Timeline,
not all retained history. Missing identity fields are labelled **Not recorded**.
Counts combine recorded event types; they are not workflow completion or
failure rates. Workflow/run grouping is not provided by this feed yet.
For daily token and cost charts, use **Analytics**.

The chart follows AtMem typography, supports both themes, and uses labelled
keyboard-operable bars. It does not change ingestion, permissions or storage.
