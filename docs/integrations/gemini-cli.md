# Gemini CLI and AtFlows

**Status: telemetry setup recipe pending validation.** The former example README contained unverified Gemini CLI settings and endpoint keys. They have been removed until a supported Gemini CLI release is tested against the installed AtFlows receiver.

AtFlows receives OTLP/HTTP at its dashboard port, which varies by launcher and configuration. The receiver's format must match the exporter. See [connection basics](./atflows-basics.md) and the planned [guided setup feature](../../specs/006-guided-integrations/spec.md).
